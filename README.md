### 🛡️ Dragon of North

*A production-deployed authentication & security platform.*
*Not a tutorial. Not a CRUD app. A real system.*

</div>

```
┌──────────────────────────────────────────────────────────────────────┐
│                  DRAGON OF NORTH — Architecture                      │
├─────────────────┬──────────────────────────┬─────────────────────────┤
│  CLIENT         │  API LAYER               │  INFRA LAYER            │
├─────────────────┼──────────────────────────┼─────────────────────────┤
│  React SPA      │  Spring Boot (Java 21)   │  PostgreSQL (AWS RDS)   │
│  app.verloren   │  JWT / RSA-2048 Signing  │  Redis (Rate Limiting)  │
│  .dev           │  OAuth2 Resource Server  │  AWS EC2 + SES + SNS    │
│                 │  Device-Aware Sessions   │  Docker + Compose       │
│                 │  OTP Verification        │  GitHub Actions CI/CD   │
│                 │  Micrometer + Swagger    │  Flyway Migrations      │
│                 │  Redis Rate Limiting     │  k6 Load Testing        │
└─────────────────┴──────────────────────────┴─────────────────────────┘
```

| Feature | Detail |
|---------|--------|
| 🔐 **JWT / RSA-2048** | Asymmetric signing — stateless, rotatable access + refresh tokens |
| 📱 **Device Fingerprinting** | Sessions bound to device context, not just user identity |
| 🚦 **Redis Rate Limiting** | Per-IP + per-user sliding window — bot-resistant by design |
| 📧 **OTP via AWS SES + SNS** | Email & SMS verification before account activation |
| 🔄 **219+ Prod Deployments** | GitHub Actions → EC2, zero-downtime on every push |
| 📊 **Micrometer + Prometheus** | Full observability, production metrics always live |
| 🧪 **k6 Load Tests** | Concurrent auth pressure validated before every release |

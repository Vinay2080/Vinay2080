## 🚀 Projects

### 🛡️ Dragon of North — Production Auth Platform

> A production-deployed authentication & security platform. Not a tutorial. Not a CRUD app.

```
┌──────────────────────────────────────────────────────────────────────┐
│                    DRAGON OF NORTH — Architecture                    │
├────────────────┬───────────────────────────┬─────────────────────────┤
│  CLIENT        │  API LAYER                │  INFRA LAYER            │
├────────────────┼───────────────────────────┼─────────────────────────┤
│  React SPA     │  Spring Boot (Java 21)    │  PostgreSQL (AWS RDS)   │
│  app.verloren  │  JWT / RSA-2048 Signing   │  Redis (Rate Limiting)  │
│  .dev          │  OAuth2 Resource Server   │  AWS EC2 + SES + SNS    │
│                │  Device-Aware Sessions    │  Docker + Compose       │
│                │  OTP Verification         │  GitHub Actions CI/CD   │
│                │  Micrometer + Swagger     │  Flyway Migrations      │
│                │  Redis Rate Limiting      │  k6 Load Testing        │
└────────────────┴───────────────────────────┴─────────────────────────┘
```

**Key features:**

- 🔐 **JWT/RSA-2048** — asymmetric signing, stateless access + refresh token rotation
- 📱 **Device fingerprinting** — sessions bound to device context, not just identity
- 🚦 **Redis rate limiting** — per-IP + per-user sliding window, bot-resistant
- 📧 **OTP via AWS SES + SNS** — email & SMS verification before account activation
- 🔄 **219+ production deployments** — GitHub Actions → EC2, zero-downtime
- 📊 **Micrometer + Prometheus** — full observability, metrics exposed in prod
- 🧪 **k6 load tests** — concurrent auth pressure validated before every release
